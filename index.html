Start Pick-Me with its local server

This source file is a Vite application entry point. Opening it as a standalone HTML visualization does not compile or start the app.

From the Pick-Me folder, run:

npm ci
npm run dev -- --port 5173 --strictPort

Then open http://127.0.0.1:5173 on the same machine. For a production preview, run npm run build and npm run preview -- --port 4173 --strictPort.

This message is replaced when the application loads successfully.
